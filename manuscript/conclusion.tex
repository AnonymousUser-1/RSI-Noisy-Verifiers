\section{Conclusion}
\label{sec:conclusion}

Matched rates, yield, and precision can conceal opposite updates
and long-run population outcomes. Our construction links this separation
to accepted-error influence and yields a sharp threshold for a specified
group-targeted audit. Finite-pool analysis connects error selection to
updates while distinguishing reference loss from task risk.
Across three language models, both four-round graph arms improve; Qwen3-1.7B's
unaudited arms differ in error composition, while primary one-step ID
accuracy contrasts remain small. These findings motivate evaluating
error identity alongside acceptance rates.
